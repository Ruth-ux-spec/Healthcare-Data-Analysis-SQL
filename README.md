# Healthcare-Data-Analysis-SQL
A SQL project analyzing hospital data to identify trends, patient information, and healthcare insights.

## Project Overview

This project uses SQL queries to analyze healthcare data and provide insights into patient records, billing information, hospital performance, and treatment patterns.

## Tools Used

- SQL
- SQL Server Management Studio (SSMS)

## Business Problems

- Which blood type is most common among patients?
- Which medical condition occurs most frequently?
- What is the average billing amount?
- Which hospital has the highest number of patients?
- Are there any missing values in the dataset?
- What age group has the highest number of patients?

## SQL Skills Demonstrated

- SELECT Statements
- WHERE Clause
- ORDER BY
- GROUP BY
- COUNT()
- AVG()
- MIN() and MAX()
- Handling NULL values
- Data Cleaning and Data Exploration

## Conclusion

This analysis demonstrates how SQL can be used to extract meaningful insights from healthcare data and support data-driven decision-making.
